# VITyarthi-Project
                                                        PYTHON TYPING SPEED TESTER

Introduction
The Python Typing Speed Tester was designed to measure your typing performance from the command line. It will provide you with random sentences, track your time, and calculate both your Words Per Minute and accuracy. The tool is a straightforward, effective way to practice touch typing and analyze progress.

Project Aim
The objective of this project is to provide a lightweight utility to users that will help them in improving their typing skills.

Key Objectives :
1) Calculate WPM correctly.
2)Measure the Accuracy % by comparing the user input with the target text.
3) Provide immediate feedback about performance.
4) Demonstrate the usage of Python string manipulation and time modules.

Tools and Technologies
This project is built using standard Python libraries:
Language - Python 3
Time Tracking – time module
Randomization – random module
User Interface Command Line Interface (CLI)

How It Works
The program logic flow is as follows:
1. Selection: The program randomly selects a sentence from some predefined list or from a text file.
2. Timer Start: The system records the exact start time when the user hits Enter to start.
3.  Input : The user types the sentence.
4.  Timer Stop :  The system records the end time when the user submits the text.
5. Calculations :-
• WPM formula:  (Total Characters / 5) / (Time in Minutes)
• Accuracy Formula : (Correct Characters / Total Characters) * 100
